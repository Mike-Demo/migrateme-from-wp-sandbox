The run

This site is the output of the migrateme.tech toolkit's first real-world run — not a mockup. The source is the live WordPress testbed at wp.sandbox.migrateme.tech (DXS, the Digital Experience Showcase). Its WXR export was run through the toolkit on October 14, 2026: plan, dry run, approved migration, validation. Every page below is one migrated item, rendered from the exact file the engine wrote; the raw Markdown is one click away on each page, and the full run manifest is here.
