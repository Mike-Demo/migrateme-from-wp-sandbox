About this testbed

DXS (Digital Experience Showcase) is an open content test bed built for migrateme.tech — an AI-assisted CMS migration toolkit. This WordPress edition is one of three: the app editions live at lovable.sandbox.migrateme.tech and lovable.cloud.sandbox.migrateme.tech. All three share the same content contract so a migration engine can be cross-verified across platforms.

This site is seeded with real publication states, taxonomy hierarchies, and comment threads — not lorem ipsum. Read more about the testbed, or review the methodology and fixtures.
