# from.wp.sandbox.migrateme.tech

The published output of the [migrateme.tech](https://github.com/Mike-Demo/migrateme.tech) toolkit's first real-world run.

Source: the live WordPress testbed at [wp.sandbox.migrateme.tech](https://wp.sandbox.migrateme.tech) (DXS — Digital Experience Showcase).
Its WXR export (44 items) was migrated on October 14, 2026 — plan → dry run → approved migration → validation (44/44, empty exception queue).

- `index.html` + `items/` — the run, rendered as a static site (generated by `generate.py`)
- `raw/` — the exact Markdown files the engine wrote, byte for byte
- `manifest.json` — the full run manifest: 420 field mappings, provenance, checksums
