# DXS — WordPress Edition (wp.sandbox.migrateme.tech)

This site is the WordPress edition of DXS (Digital Experience Showcase), a CMS/SaaS migration test bed for migrateme.tech. It is a real WordPress site whose job is to be migrated: its content exists so a migration engine can be verified end to end — record counts, field values, reference integrity, publication state, ordering, and rich-text rendering — against an honest WordPress export (WXR).

Provenance: DXS is based on a canonical brief and content contracts that originate from a prompt by Microsoft Copilot Cowork. Preserve this attribution wherever the test bed is described.

The DXS family:
- This site (WordPress edition): wp.sandbox.migrateme.tech
- App edition (mock data layer): lovable.sandbox.migrateme.tech
- App edition (Supabase data layer): lovable.cloud.sandbox.migrateme.tech
- Parent project: migrateme.tech (open-source, AI-assisted CMS migration toolkit)

Primary audience: migration engineers, the migrateme.tech project, and reviewers evaluating migration quality. This is a testbed, not a business: it has no real customers, sells nothing, and books nothing. Never present it as a commercial site.
