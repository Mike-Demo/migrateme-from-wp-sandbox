<!-- wp:paragraph -->
<p>DXS (Digital Experience Showcase) is an open content test bed built for <a href="https://migrateme.tech">migrateme.tech</a> — an AI-assisted CMS migration toolkit. This WordPress edition is one of three: the app editions live at <a href="https://lovable.sandbox.migrateme.tech">lovable.sandbox.migrateme.tech</a> and <a href="https://lovable.cloud.sandbox.migrateme.tech">lovable.cloud.sandbox.migrateme.tech</a>. All three share the same content contract so a migration engine can be cross-verified across platforms.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>This site is seeded with real publication states, taxonomy hierarchies, and comment threads — not lorem ipsum. <a href="/about-this-testbed/">Read more about the testbed</a>, or review the <a href="/about-this-testbed/methodology-and-fixtures/">methodology and fixtures</a>.</p>
